## Learning Path

A practical progression through this collection:

1. **Start with tabnabbing fundamentals**  
   Begin with Tabnapped and Sleeping Tabs to understand the collection's primary web-security theme.

2. **Study tabnabbing investigation**  
   Continue with Sleepy Tabs: Stealthy Steals, Tabnapping Trail, and Sleeping Tabs 2.

3. **Build reconnaissance skills**  
   Work through Tabnabbing Recon and Sleepy Paths to practice structured web discovery.

4. **Learn hidden-content enumeration**  
   Complete Hidden Files Open Doors and Gobuster Hidden Web Paths.

5. **Explore application configuration**  
   Study Sleepy PHP Config and consider how configuration choices can affect web security.

6. **Finish with trust and sessions**  
   Use Tabbed Trust and Sleeping Sessions to broaden your understanding of browser and authentication-related security concepts.

## How to Use the Labs

- Use every lab only in an authorized CTF or cybersecurity training environment.
- Begin with reconnaissance and document what is publicly observable.
- Use web-enumeration tools such as Gobuster only against authorized targets.
- Treat hidden files, paths, and session information as controlled lab data.
- For PHP configuration challenges, focus on understanding the security impact of configuration choices.
- For tabnabbing challenges, study both the attack concept and appropriate defensive controls.
- Keep notes on discovered clues, evidence, and recommended mitigations.
